How they’re built

One shared stack. AI that proposes, people who decide.

The stack, layer by layer

  1. Client

    Interfaces people enjoy using, on the web and on staff phones.

    Angular 21 · React Native / Expo · TypeScript

  2. Services

    Serverless backends, built multi-tenant.

    .NET 8 · Azure Functions · C#

  3. Data

    Documents, relations and embeddings, each where it fits.

    CosmosDB · Vector databases · SQL

  4. AI

    Brought in where it genuinely adds value, and grounded in real data.

    Azure AI · OpenAI · RAG · Agents

How an AI feature runs

  1. 1

    Source

    A contract, a document, a course brief: the customer’s own material.

  2. 2

    Ground

    Embedded into a vector store, ready to be retrieved.

  3. 3

    Generate

    Agents extract the obligations or build the course, grounded in what was retrieved.

  4. 4

    Review

    A person checks and approves. The AI proposes; it does not decide.

  5. 5

    Trace

    Every step is kept in an audit-ready trail.
