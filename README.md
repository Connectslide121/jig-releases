# Jig releases

Installers and update feeds for Jig, a desktop workbench around Claude Code and Codex (Windows).

Download the latest `Jig-Setup-<version>.exe` from [Releases](https://github.com/Connectslide121/jig-releases/releases/latest).
An installed Jig finds new versions here by itself and offers **Install and restart**.

The source code lives in a private repository; this repository holds only the release pages and their files.
